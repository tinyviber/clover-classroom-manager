Windows x64 管理端
========================

运行 Clover-Classroom-Manager.exe 启动管理端。首次启动会在当前用户数据目录生成管理端密钥和设备注册表；请定期备份该目录，管理端密钥用于学生端验证身份。

本压缩包同时包含 agent.exe。管理端可使用“分发客户端”导出包含当前管理端地址和公钥的学生端安装包。

学生机首次部署请在还原软件解冻状态下安装，确认管理端看到设备上线后再冻结。Windows 可能对未签名程序显示 SmartScreen 提示。
